### Описание

Этот проект — включает тестирование следующих сервисов:

* **UI** 👉 [Banking Project](https://www.globalsqa.com/angularJs-protractor/BankingProject/#/login)
* Внутреннее **API** тестового полигона PFLB

---

* Автотесты к кажому из проектов лежат в соответствующих модулях `API` и `UI` соответственно.
* На ветке `gh_pages` доступен Allure-отчёт: 👉 [Актуальный Allure отчёт](https://zen2281488.github.io/jqe_ui_api/)
* CI workflow: `.github/workflows/runTests.yml`

---

### 🛠 Установка и запуск

#### ✅ Требования

* Java 17+
* Maven 3.8+
* Git
* Allure CLI (для генерации отчётов)

---

### 🚀 Пошаговый запуск

#### 📥 1. Клонировать проект

```bash
git clone https://github.com/zen2281488/jqe_ui_api.git
cd jqe_ui_api
```

---

#### 🔧 2. Проверить окружение

```bash
java -version
mvn -version
```

---

#### ⚙️ 3. Собрать проект

```bash
mvn clean install
```

---

#### 🔐 4. Подготовить параметры запуска

Перед запуском тестов необходимо передать следующие параметры в виде `-D` флагов для Maven:

| Параметр       | Назначение                       |
| -------------- | -------------------------------- |
| `DB_USER`      | Пользователь БД (PostgreSQL)     |
| `DB_PASSWORD`  | Пароль пользователя БД           |
| `API_USER`     | Логин тестового API-пользователя |
| `API_PASSWORD` | Пароль API-пользователя          |
| `BASE_URL`     | Базовый URL для запросов к API   |

---

#### 🧪 5. Запустить тесты

> Все переменные передаются через `-D`, чтобы быть доступными через `System.getProperty(...)`

---

##### ✅ Только **API**:

```bash
cd API
mvn clean test \
  -DDB_USER=postgres \
  -DDB_PASSWORD=secret \
  -DAPI_USER=test_user \
  -DAPI_PASSWORD=super_secret \
  -DBASE_URL=https://example.com/api
```

---

##### ✅ Только **UI**:

```bash
cd UI
mvn clean test 
```

---

##### ✅ Все тесты во всех модулях:

```bash
mvn clean test \
  -DDB_USER=postgres \
  -DDB_PASSWORD=secret \
  -DAPI_USER=test_user \
  -DAPI_PASSWORD=super_secret \
  -DBASE_URL=https://example.com/api \
  -Dallure.results.directory=target/allure-results \
  -fail-at-end
```
  
##### 📊 6. Сформировать Allure отчёт

Установить Allure CLI:
<details>
<summary>Ubuntu/macOs</summary>

```bash
# macOS
brew install allure
```
```bash
# Ubuntu / Debian
sudo apt install allure
```
</details>

<details>
<summary>Windows</summary>

1. Перейди на страницу релизов Allure:
   👉 [https://github.com/allure-framework/allure2/releases](https://github.com/allure-framework/allure2/releases)

2. Скачай `.zip` архив с последним релизом, например `allure-2.23.0.zip`.

3. Распакуй его, например в:
   `C:\allure`

4. Добавь путь к папке `bin` в системную переменную `Path`:

  * Открой "Переменные среды"
  * Найди переменную `Path` → Изменить → Добавить:
    `C:\allure\bin`

5. Проверь в консоли:

```powershell
allure --version
```
</details>
---

Сгенерировать и открыть отчёт:

```bash
allure serve target/allure-results
```

Или сохранить в директорию:

```bash
allure generate target/allure-results -o target/allure-report --clean
```

## 📌 **API кейсы**

### 1️⃣ **Создание пользователя**

| Параметр    | Значение                                                                                                                                                                                                                       |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Эндпоинт    | `POST /user`                                                                                                                                                                                                                   |
| Предусловие | Получить токен через `POST /login` с `username` и `password`                                                                                                                                         |
| Шаги    | 1) Отправить `POST /user` с телом `{ "firstName": "Тест", "lastName": "Тестовлев", "age": 18, "sex": "MALE", "money": 12997 }`<br>2) Проверить ответ (код 201 и тело).<br>3) Проверить, что запись создана в таблице `person`. |
| Ожидаемое   | 1) Код 201 <br> 2) Вернулся ID и корректные данные <br> 3) В таблице `person` создана запись                                                                                                                                   |

---
